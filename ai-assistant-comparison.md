## Notes per service

- **ChatGPT** — All-rounder. GPT-6 Astra (Sep 2026), Images 2.5, "dots" always-on agents rolling out to Pro/Business Premium. Free tier has ads in the US.
- **Claude** — Strongest at coding and long agent tasks; Docs, Slides and Design built into chats (Sep 2026). No native image or video generation. Training can be turned off (30-day retention).
- **Gemini** — Best for Google Workspace/Android users. New Windows app (Alt+Space), reusable skills replacing Gems, most cloud storage on AI Pro.
- **Grok** — Live X/Twitter data. Free tier lost image/video generation in March 2026; paid video now 1080p.
- **Perplexity** — Best for cited research. Pro includes multiple frontier models, Labs (sheets, dashboards, mini-apps), 3 Veo videos/month, Comet browser.
- **Copilot** — Best for Word/Excel/PowerPoint. Consumer Deep Research, podcasts and group chats removed Aug 2026; new Code feature for small apps; usage-based billing coming.
- **Meta AI** — Free, built into WhatsApp/Instagram/Messenger. Video via Vibes. Least suited to serious work.
- **DeepSeek** — Strong free reasoning, 1M context. No image generation; voice only in limited testing. Data stored in China.
- **Mistral Vibe** (formerly Le Chat, renamed May 2026) — EU-hosted, privacy-friendly. Work Mode, Code Mode, deep research, voice, 100+ connectors.
- **Qwen** — Free and capable (reports, slides, coding). Integrations mainly China-based (Taobao, Alipay, Amap). Data stored in China.
